# XaDa GitHub Pages website

1. Upload every file in this folder to the root of your GitHub Pages repository.
2. Put custom images and music in an `assets` folder.
3. Edit only `site-config.js` to change the logo, music, colours, carousel products, product pictures or link buttons.

No API key, proxy or server is required. Music starts only after a visitor presses the AMBIENCE button because browsers block automatic sound playback.
